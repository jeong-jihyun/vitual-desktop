# 버그 리포트 관리

사용자가 실기 테스트 중 보내주는 스크린샷/로그를 정리해두는 곳이다.
**원본 파일(`attachments/`)은 git 형상관리 대상이 아니다** (`.gitignore` 처리,
개인 화면 캡처·로그가 저장소에 들어가지 않도록) - 이 `README.md`(이력 목록)만
프로젝트에 함께 커밋되어 "어떤 문제가 언제 있었고 어떻게 됐는지"가 코드와
같이 남는다.

## 폴더 구조

```
bug-reports/
  README.md          <- 이 파일. 이슈 이력 표 (git 추적됨)
  attachments/        <- 스크린샷, 로그 첨부파일 원본 (git 추적 안 됨)
    2026-09-13_video-black-screen/
      screenshot.png
      agent.log
```

## 이슈 이력

| 날짜 | 증상 | 관련 첨부 | 상태 | 조치/커밋 |
| --- | --- | --- | --- | --- |
| _(아직 없음)_ | | | | |

## 사용 방법

1. 사용자가 스크린샷/`agent.log`/`server.log`/진단 리포트 텍스트를 대화창에 보내면,
   `bug-reports/attachments/<날짜>_<짧은-설명>/` 폴더를 만들어 원본을 저장한다.
2. 위 "이슈 이력" 표에 한 줄 추가한다 (날짜, 증상 요약, 첨부 경로, 상태).
3. 원인을 찾아 코드를 고치면, 그 커밋 해시를 "조치/커밋" 칸에 적고 상태를 "해결"로 바꾼다.
4. 재현이 안 되거나 사용자 확인 대기 중이면 상태를 "확인 중"으로 둔다.

상태 값: `접수` / `확인 중` / `해결` / `보류`
